反汇编算法

  • 线性反汇编

具体原理：从一个代码段的第一个字节开始，以线性模式扫描整个代码段，逐条反汇编每条指令，直到完成整个代码段。

优点：能够完全覆盖程序的所有代码段。

缺点：没有考虑到代码中可能混有数据。

主要工具：GDB

  • 面向代码流的反汇编，也被称做递归下降反汇编算法

具体原理：递归下降算法强调控制流的概念。控制流根据一条指令是否被另一条指令引用来决定是否对其进行反汇编。

优点：具有区分代码与数据的强大能力。

缺点：无法处理间接代码路径。

主要工具：IDA、windbg

函数指针：添加代码的交叉引用

mov [ebp+var_4], offset sub_4011c0;
push 2Ah;
call [ebp+var_4];

​ 原理：如果在汇编语言中可以使用函数指针或者在源码中构造不标准的函数指针格式，会导致在没有动态分析的前提下很难进行逆向分析。

​ 解决方案：在IDA中添加代码的交叉引用，使用IDC中名为AddCodeXref函数，有三个参数：交叉引用来源的位置、交叉引用指向的位置、以及流的类型。
$$
AddCodeXref(0x004011DE,0x004011C0,fl-CF)
$$
fl_cf 是 IDA Pro 中表示控制流（control flow）的标志之一。

滥用指针返回：alt+p调整函数边界，然后使用nop指令替换

        var_4    =byte ptr -4;
4011c0	call $+5;//将4011c5压入栈中
4011c5	add [esp+4+var_4],5;//将栈转化为4011CA
4011c9	retn;//调用4011CA函数

4011ca push ebp;
...
...

​ 原理：retn指令首先从栈顶弹出一个值，然后跳转到这个值所表示的地址处。（将retn放在函数中间位置来获取栈顶的值，会导致反汇编器不能显示交叉引用目标，以及提前结束这个函数，相当于填充了垃圾字符）

​ 解决方案：将retn指令前面的垃圾字符用NOP指令进行替换，然后使用alt+p的快捷键将函数的边界调整到真实的函数，可以恢复控制流。

滥用结构化异常处理（SEH）：c键转换代码

mov eax, (offset loc_40106B+1);
add eax, 14h;
//这两句汇编代码就是实现异常处理函数的构建，实际异常处理函数为loc_401080
push eax;//函数压入栈中
push  large dword ptr fs:0;
mov large fs:0, esp;
//成功加入SEH异常处理函数
xor ecx, rcx;
div ecx;
//构建除0错误

​ 原理：结构化异常处理(SEH)是用于处理异常的一个函数列表，倘若遇上异常，会按照次序依次调用SEH当中的函数进行处理。当最后一个函数也无法处理的时候会弹出对话框进行报错，滥用结构化异常处理是指在SEH链当中加入自己定义的异常处理函数来实现控制流混淆。

​ 解决方案：用C键将没有调用的子例程转换成代码进行分析。

攻击手法：利用SEH实现变相控制程序流

  • 挫败栈帧分析

​ 原理：反汇编器能够通过分析一个函数中的指令推导出函数栈的结构，能够显示局部变量以及和函数相关的参数。但是，可能出现栈指针显示为一个负数，这意味着这个函数破坏了调用函数的栈帧。

​ 解决方案：通过alt+k组合键，输入调整的栈指针值，进行修补栈帧操作指令。
